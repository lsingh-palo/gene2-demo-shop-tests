Term
Meaning
Featured
The 6 hand-picked products shown after login (catalog page).
All products
The full range of 18 products with search, filters and paging.
Subtotal
Sum of price x quantity for every cart line, before discounts.
Discount code
A promo code that reduces the price of goods: SAVE10, WELCOME5.
Shipping code
A promo code that changes shipping only: FREESHIP. Not a discount code.
Metro / Regional / Remote
Delivery regions. Metro is the default.
Surcharge
The $5.00 added to Regional shipping.
Low stock
1 to 3 items left; shown as "Only N left".
Reference build (v1)
The signed-off behaviour, used as the oracle in parity runs.
Release candidate (v2)
The build under test for release v2.0.
Parity
Running the same suite on v1 and v2 and comparing each test's result.
Requirement id
REQ-AREA-NN, the heading of each rule on the requirement pages.
