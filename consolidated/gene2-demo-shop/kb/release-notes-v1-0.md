Released 14 August 2026.
New
Customer login, locked accounts refused, session guard on every shop page.
Admin role with its own page.
Featured catalogue with sorting by name and price.
Cart with quantities and a live item badge.
Checkout with 8% tax and Metro shipping (free over $75).
Fixed
The cart badge no longer stays visible as an empty pill after the last item is removed. The
badge is now hidden whenever the cart is empty.
Tax is rounded to the nearest cent instead of being truncated.
Known issues
Checkout accepts an order without a postcode.
Double-clicking Place order can record two orders.
